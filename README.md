## Program 1: Introduction to Packet Tracer & networking devices

**File:** [Lab01_Intro_Devices.pkt](https://github.com/abhiyansh-coding/cn-lab-packet-tracer/raw/main/labs/Lab01_Intro_Devices.pkt)

**Aim:** Introduction to Packet Tracer and networking device components (routers, switches, end devices, hubs, cables).

**Also asked as:** Introduction to Cisco Packet Tracer; Study of networking devices: router, switch, hub, PC, server; Study of network cables and connectors (straight-through, crossover); Difference between router, switch and hub; Build a simple network in Packet Tracer

**Topology:** Router (2911), switch (2960), hub, PCs and a server connected with straight-through copper cables. LAN 1 (switch) = 192.168.1.0/24, LAN 2 (hub) = 192.168.2.0/24.

<details><summary><b>R1</b> configuration</summary>

```
enable
configure terminal
hostname R1
!
interface GigabitEthernet0/0
 ip address 192.168.1.1 255.255.255.0
 no shutdown
!
interface GigabitEthernet0/1
 ip address 192.168.2.1 255.255.255.0
 no shutdown
!
end
```
</details>

**Verify:**
- PC0 > `ping 192.168.2.10` (through the router)
- Click the server: HTTP service is on, open PC0 > Web Browser > `192.168.1.100`

## Program 3: Star topology using hub and switch

**File:** [Lab03_Star_Hub_Switch.pkt](https://github.com/abhiyansh-coding/cn-lab-packet-tracer/raw/main/labs/Lab03_Star_Hub_Switch.pkt)

**Aim:** Star topology using a hub and a switch, IP configuration of end devices, show command, copy command, password setting, hostname setting.

**Also asked as:** Star topology; Hub vs switch; Connect PCs using a hub / using a switch; Assign IP addresses to PCs; Set hostname and passwords on a switch; Save configuration (copy running-config startup-config); Basic show commands on a switch; Collision domain vs broadcast domain

**Topology:** Star 1: 3 PCs on a hub (192.168.1.0/24). Star 2: 3 PCs on switch SW1 (192.168.2.0/24). SW1 has hostname, console/vty password `cisco`, enable secret `class`, banner, and the config is saved (`copy running-config startup-config`).

<details><summary><b>SW1</b> configuration</summary>

```
enable
configure terminal
hostname SW1
!
enable secret class
banner motd #Authorized access only#
!
interface Vlan1
 ip address 192.168.2.2 255.255.255.0
 no shutdown
!
line con 0
 password cisco
 login
line vty 0 4
 password cisco
 login
!
end
```
</details>

**Verify:**
- PC0 > `ping 192.168.1.12`, PC3 > `ping 192.168.2.12`
- Simulation mode: send a PDU on the hub side (it floods to all ports) vs the switch side (only the destination port)
- SW1 CLI (password `cisco`, enable `class`): `show running-config`, `show startup-config`, `show mac-address-table`, `show ip interface brief`

## Program 4: DHCP on a router

**File:** [Lab04_DHCP.pkt](https://github.com/abhiyansh-coding/cn-lab-packet-tracer/raw/main/labs/Lab04_DHCP.pkt)

**Aim:** Configure DHCP on a router to assign IP addresses to devices dynamically, and verify the configuration.

**Also asked as:** Dynamic Host Configuration Protocol; Configure a router as DHCP server; Automatic IP address assignment; DHCP pool, excluded addresses, default-router, dns-server; Configuration of PC using switch and router; show ip dhcp binding

**Topology:** R1 is the DHCP server for 192.168.1.0/24 (pool MY_POOL, .1 to .10 excluded). All PCs are set to DHCP.

<details><summary><b>R1</b> configuration</summary>

```
enable
configure terminal
hostname R1
!
ip dhcp excluded-address 192.168.1.1 192.168.1.10
!
ip dhcp pool MY_POOL
 network 192.168.1.0 255.255.255.0
 default-router 192.168.1.1
 dns-server 8.8.8.8
!
interface GigabitEthernet0/0
 ip address 192.168.1.1 255.255.255.0
 no shutdown
!
end
```
</details>

**Verify:**
- PC > Desktop > IP Configuration: DHCP (click it again if it shows 169.254.x.x). The PC should get 192.168.1.11+
- R1: `show ip dhcp binding`, `show ip dhcp pool`
- PC0 > `ipconfig /all`, then ping another PC

## Program 5: Router modes and basic router/switch commands

**File:** [Lab05_Router_Switch_Basics.pkt](https://github.com/abhiyansh-coding/cn-lab-packet-tracer/raw/main/labs/Lab05_Router_Switch_Basics.pkt)

**Aim:** Understand the modes of a router and explore basic router and switch commands for configuring and managing network devices.

**Also asked as:** Router modes (user EXEC, privileged EXEC, global config, interface config); Basic router commands / basic switch commands; Configure router interface IP and no shutdown; Hostname, enable secret, console password, banner; show ip interface brief / show running-config / show vlan brief; Router mode, switch/router basic commands

**Topology:** MyRouter (hostname, interface IP, passwords, banner) and MySwitch with VLAN 10 `Sales` on Fa0/1, Fa0/2, Gi0/1. Console password `cisco`, enable secret `class`.

<details><summary><b>MyRouter</b> configuration</summary>

```
enable
configure terminal
hostname MyRouter
!
enable secret class
banner motd #MyRouter - authorized access only#
!
interface GigabitEthernet0/0
 description LAN to MySwitch
 ip address 192.168.1.1 255.255.255.0
 no shutdown
!
line con 0
 password cisco
 login
line vty 0 4
 password cisco
 login
!
end
```
</details>

<details><summary><b>MySwitch</b> configuration</summary>

```
enable
configure terminal
hostname MySwitch
!
enable secret class
!
interface FastEthernet0/1
 switchport mode access
 switchport access vlan 10
!
interface FastEthernet0/2
 switchport mode access
 switchport access vlan 10
!
interface GigabitEthernet0/1
 switchport mode access
 switchport access vlan 10
!
end
```
</details>

**Verify:**
- Modes: `Router>` → `enable` → `Router#` → `configure terminal` → `(config)#` → `interface g0/0` → `(config-if)#`
- MyRouter: `show ip interface brief`, `show running-config`, `show version`
- MySwitch: `show vlan brief` (VLAN 10 Sales: Fa0/1, Fa0/2, Gi0/1)
- PC0 > `ping 192.168.1.1`

## Program 6: Static routing

 no shutdown
!

!
end
```
</details>

enable
configure terminal
hostname R2

 ip address 192.168.2.1 255.255.255.0
 no shutdown
!
interface GigabitEthernet0/1
 ip address 10.0.0.2 255.255.255.252
 no shutdown
!
ip route 192.168.1.0 255.255.255.0 10.0.0.1
!
end
```
</details>

**Verify:**

## Program 7a: RIP version 1

**File:** [Lab07a_RIPv1.pkt](https://github.com/abhiyansh-coding/cn-lab-packet-tracer/raw/main/labs/Lab07a_RIPv1.pkt)

**Aim:** Configure Routing Information Protocol (RIP) on routers to enable dynamic routing between multiple networks: version 1.

**Also asked as:** RIP / RIPv1; Dynamic routing using distance-vector protocol; Classful routing protocol; Configuration of RIPv1 and RIPv2; Hop count metric

**Topology:** Three routers in a line: R1 to R2 on 10.0.0.0/30, R2 to R3 on 10.0.0.4/30, and each router has a LAN (192.168.1/2/3.0/24). RIPv1 advertises every network. RIPv1 is classful and sends no subnet masks.

<details><summary><b>R1</b> configuration</summary>

```
enable
configure terminal
hostname R1
!
interface GigabitEthernet0/0
 ip address 192.168.1.1 255.255.255.0
 no shutdown
!
interface GigabitEthernet0/1
 ip address 10.0.0.1 255.255.255.252
 no shutdown
!
router rip
 version 1
 network 192.168.1.0
 network 10.0.0.0
!
end
```
</details>

<details><summary><b>R2</b> configuration</summary>

```
enable
configure terminal
hostname R2
!
interface GigabitEthernet0/0
 ip address 192.168.2.1 255.255.255.0
 no shutdown
!
interface GigabitEthernet0/1
 ip address 10.0.0.2 255.255.255.252
 no shutdown
!
interface GigabitEthernet0/2
 ip address 10.0.0.5 255.255.255.252
 no shutdown
!
router rip
 version 1
 network 192.168.2.0
 network 10.0.0.0
!
end
```
</details>

<details><summary><b>R3</b> configuration</summary>

```
enable
configure terminal
hostname R3
!
interface GigabitEthernet0/0
 ip address 192.168.3.1 255.255.255.0
 no shutdown
!
interface GigabitEthernet0/1
 ip address 10.0.0.6 255.255.255.252
 no shutdown
!
router rip
 version 1
 network 192.168.3.0
 network 10.0.0.0
!
end
```
</details>

**Verify:**
- Wait about 30 s for convergence, then PC0 > `ping 192.168.3.10`
- R1: `show ip route` (R = RIP, metric [120/hops])
- R1: `show ip protocols`, `debug ip rip` (`undebug all` to stop)
